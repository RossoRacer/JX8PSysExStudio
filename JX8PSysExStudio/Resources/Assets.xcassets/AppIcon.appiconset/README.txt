JX-8P Morph — macOS AppIcon

This folder is an Xcode-ready AppIcon.appiconset.

Installation:
1. Open your Xcode project.
2. Open Assets.xcassets.
3. Replace/rename the existing AppIcon set as appropriate.
4. Drag this entire AppIcon.appiconset folder into Assets.xcassets in Finder/Xcode,
   or copy its contents into an existing AppIcon.appiconset.
5. In the app target's General settings, make sure the App Icons asset is selected.

The asset contains 1x and 2x PNGs for the standard macOS App Icon sizes.
